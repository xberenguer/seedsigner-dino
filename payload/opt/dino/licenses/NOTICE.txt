Native Dino runner

The Python game adapts the original Chromium Dino game, using its original 1x
sprite sheet and game constants, collision geometry, and movement rules.
The bundled artwork is unmodified. No endorsement by Google is implied.

Adaptation changes: native Python/Pillow rendering, GPIO-independent held-button
inputs, fixed 60Hz simulation, a 320x150 viewport, a scaled maximum speed,
volatile RAM-only score, and no browser/DOM, networking, audio, or persistent
high-score storage. The host application owns device controls and mode changes.
